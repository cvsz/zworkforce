# Frontend Dashboard UI/UX Stack

## Installed Options

| Option | Location | Purpose |
|---|---|---|
| **ReUI Dashboard** | `apps/frontend/reui-dashboard/` | Dashboard shell with shadcn/ui + ReUI patterns |
| **Canva App** | `apps/frontend/canva-app/` | Canva App UI Kit side-panel dashboard module |
| **MetricUI Analytics** | `apps/frontend/metricui-analytics/` | Analytics dashboard with KPI cards and charts |
| **Canva Dev MCP** | `apps/frontend/mcp/` | MCP server for AI-assisted Canva development |

## Quick Start

```bash
# ReUI Dashboard
cd apps/frontend/reui-dashboard
pnpm install
pnpm dev

# Canva App
cd apps/frontend/canva-app
pnpm install
pnpm dev

# MetricUI Analytics
cd apps/frontend/metricui-analytics
pnpm install
pnpm dev
```

## Canva MCP Setup

```bash
cd apps/frontend/mcp
bash setup-canva-mcp.sh
```
