# Canva App UI Kit Dashboard Module

This app demonstrates Canva App UI Kit integration for z-platform dashboard configuration.

## Setup

```bash
cd apps/frontend/canva-app
pnpm install
pnpm dev
```

## Features

- Canva App UI Kit components (`@canva/app-ui-kit`)
- Design Editor intent (`@canva/intents/design`)
- Form fields, toggles, badges, and buttons
- Theme and notification settings

## Canva Integration

This app is designed to run inside Canva's design editor as a side-panel app.
