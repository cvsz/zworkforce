# MetricUI Analytics Dashboard

z-platform analytics dashboard scaffolded with MetricUI patterns.

## Setup

```bash
cd apps/frontend/metricui-analytics
pnpm install
pnpm dev
```

## MetricUI Components

Install MetricUI:
```bash
npm install metricui
```

Reference: https://github.com/mpmcgowen/metricui

## Integration Notes

- Analytics shell: `app/page.tsx`
- UI primitives: `components/ui/`
- MetricUI components will be added under `components/metricui/`
