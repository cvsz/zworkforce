---
name: zeaz-model-routing
description: Selects model tiers by task difficulty, latency, capability, quality, privacy, and measured cost.
version: 1.0.0
---
Start with the lowest-cost model that meets evaluated quality and capability requirements. Route complex, ambiguous, security-sensitive, or high-impact work to stronger models only when evidence supports it. Use fast models for validated high-volume classification/extraction. Keep model IDs, prices, limits, and availability in maintained configuration; do not hardcode changing vendor facts from a guide. Bound escalation and log model version, token usage, latency, retries, quality, and cost while minimizing sensitive data.
