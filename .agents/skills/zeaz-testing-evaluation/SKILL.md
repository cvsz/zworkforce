name: zeaz-testing-evaluation
description: Builds layered test suites for software behavior, LLM quality, and agent tool safety.
version: 1.0.0
---
Map every acceptance criterion to a test. Cover unit, integration, contract, E2E, migration, resilience, and security cases by risk. For LLMs use representative datasets, constraints, adversarial cases, and reviewed labels. Measure task success, groundedness, schema validity, refusal correctness, latency, cost, and unsafe tool attempts. Compare against baseline and record SHA, environment, commands, results, skips, and limitations. Define thresholds before testing.
