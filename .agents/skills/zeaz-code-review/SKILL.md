---
name: zeaz-code-review
description: Reviews changes for correctness, regression, security, compatibility, and maintainability.
version: 1.0.0
---
Read repository instructions, full diff, call sites, tests, and relevant history. Prioritize concrete bugs and security risks. Check validation, authorization, tenancy, concurrency, idempotency, cleanup, error paths, and compatibility. Each finding needs severity, path/line, trigger, impact, evidence, and actionable fix. Distinguish confirmed defects from hypotheses. Never recommend approval from a partial diff.
