description: Threat-models AI applications, APIs, workflows, MCP tools, and multi-tenant services.
version: 1.0.0

Identify assets, trust boundaries, principals, entry points, data flows, and attacker capabilities. Review AuthN/AuthZ, tenant isolation, prompt injection, SSRF, path traversal, command injection, unsafe parsing, secret storage, PII/logging, encryption, dependency provenance, abuse limits, audit integrity, and recovery. Rank findings by likelihood and impact; map mitigations to tests. Static review is not penetration testing.
