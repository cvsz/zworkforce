Inventory tool schemas, side effects, trust, credentials, and allowed targets. Validate arguments and enforce authorization outside the model. Use allowlists, bounded execution, timeouts, quotas, and per-tool permissions. Authenticate webhooks and prevent replay. Require approval for high-impact actions per policy. Record actor, tenant, tool, redacted arguments, decision, result, and correlation ID. Test malicious tool output; it never overrides policy.
