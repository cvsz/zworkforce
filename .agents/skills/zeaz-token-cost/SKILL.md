---
name: zeaz-token-cost
description: Controls LLM token cost with budgets, caching, batching, output limits, and telemetry.
version: 1.0.0
---
Estimate tokens with provider APIs where available. Enforce per-task and per-tenant budgets server-side. Bound outputs and select context by relevance. Cache stable context only when privacy, provider semantics, and invalidation allow it. Batch only when latency and terms permit. Use maintained prices and include retries, cached tokens, tools, images, and billable failures. Alert on anomalies and isolate tenant usage.
